COPIA DE DEMOSTRACION PARA REVISION

Esta copia conserva las vistas, estilos, formularios y JavaScript de la aplicacion original.
El backend fue sustituido por respuestas locales de solo lectura con datos ficticios.
No es una copia operativa de produccion ni permite validar las integraciones originales.

INICIAR
1. Extraer el ZIP completo.
2. Usar PHP 8.0 o superior. No requiere Composer, SQL Server ni extensiones SQL/cURL.
3. En Windows abrir INICIAR_DEMO.bat, o ejecutar desde esta carpeta:
   php -S 127.0.0.1:8095 -t .
4. Abrir http://127.0.0.1:8095/View/login.php
5. Codigo: DEMO. Contrasena: DEMO. Son valores publicos de ejemplo.
6. Para terminar, cerrar el servidor o presionar Ctrl+C.
