COPIA DE DEMOSTRACION PARA REVISION

Esta copia conserva las vistas, estilos, formularios y JavaScript de la aplicacion original.
El backend fue sustituido por respuestas locales de solo lectura con datos ficticios.
No es una copia operativa de produccion ni permite validar las integraciones originales.

INICIAR
1. Extraer el ZIP completo.
2. Usar PHP 8.0 o superior. No requiere Composer, SQL Server ni extensiones SQL/cURL.
3. En Windows abrir INICIAR_DEMO.bat, o ejecutar desde esta carpeta:
   php -S 127.0.0.1:8095 -t .
4. Abrir http://127.0.0.1:8095/View/login.php
5. Codigo: DEMO. Contrasena: DEMO. Son valores publicos de ejemplo.
6. Para terminar, cerrar el servidor o presionar Ctrl+C.

PARA REVISAR
- Inicio, menu, preingreso y formulario de entrevista con sus pasos.
- Dotaciones: tres personas ficticias; busqueda, filtros, detalle y formulario de edicion.

Los movimientos se almacenan en localStorage y comparten datos con el simulador de control cuatrimestral. El backend real sigue bloqueado en DEMO.
- Control cuatrimestral y adelantos: abrir desde Dotaciones -> "Control cuatrimestral y adelantos · DEMO".
  * Entregas normales solo en abril (P1), agosto (P2), diciembre (P3).
  * Cada trabajador tiene un registro principal unico por año y cuatrimestre con historial de movimientos.
  * Solo un adelanto del periodo siguiente y una entrega normal en el mes previsto.
  * El adelanto parcial bloquea solo articulos/cantidades entregados; en el mes previsto permite completar faltantes.
  * El adelanto completo cubre el periodo y bloquea una entrega normal posterior.
  * Captura de firma del receptor (y del encargado en entregas normales).
  * Fecha simulada para reproducir meses/años; ejemplo preconfigurado abril -> agosto de 2027.
  * Los movimientos se guardan solo en localStorage del navegador de prueba; "Reiniciar" borra las pruebas.
  * Este simulador NO modifica dotaciones originales ni persiste en SQL/API.
  * Programacion de prendas/cantidades por trabajador es ficticia. Reglas de servidor e integracion real pendientes.
- Datos de ejemplo fechados el 13 de noviembre de 2026 para filtros por fecha.
- Equivalencias: un articulo ficticio de solo lectura.
